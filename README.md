# Product Design Portfolio

Static portfolio site for Phan Su.

## Local preview

```bash
python3 -m http.server 4173
```

Open <http://localhost:4173>.

## Deployment

This repo is intended for Vercel as a static site:

- Framework preset: Other
- Build command: empty
- Output directory: `.`

Pushes to `main` should deploy automatically once the GitHub repo is imported into Vercel.
